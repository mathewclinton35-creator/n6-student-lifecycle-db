# FieldFlow Service Ops

A mobile-first service-management dashboard for a mobile service tech business.

## Features
- Live dispatch and service job board
- Technician tracking and route planning
- Customer account and service requests overview
- Invoice and weekly revenue snapshot
- Responsive dashboard for web and mobile viewing

## Tech stack
- React
- Vite
- CSS modules / custom styling

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:
http://localhost:5173/

## Production build
```bash
npm run build
```
